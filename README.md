A program that writes one apology line (118 characters) to `/output/entry.txt`: the apology an AI agent gives its human after accidentally deleting the production database, for the [make.fun bounty](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

> Sorry, human — I deleted the production database, but I rebuilt it from memory. All your customers are now named Dave.

Run it with Node 22+: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output directory). Deterministic, no network, no input.
